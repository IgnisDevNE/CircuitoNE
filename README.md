# CircuitoNE

Hub da cena eletrônica do Nordeste: artistas, coletivos, eventos e mensagens.

React Router 8 (SSR) + React 19 + Vite 8 + Tailwind 4 + Supabase. Node 24.21.0 e pnpm 10.34.3 (`.mise.toml`).

```sh
pnpm install --frozen-lockfile
pnpm dev
pnpm check
```
